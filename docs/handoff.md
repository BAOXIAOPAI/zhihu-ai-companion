# 双人交接与验收

## 分工与进度

1. 硬件负责人先做 G 屏横屏与触摸、三模块采样、指定 MP3 播放。同步拍带尺实物图。
2. 手机与后端负责人先做模拟设备、H5 状态与控制，通过模拟确认回执后接知乎搜索、直答。
3. 第一次真机联调完成实测数据上报、手机切屏、设备确认、早报同步。随后验证用户改变兴趣和设备断网。
4. 最后验证抽屉、屏幕框和 USB-C。旧件不用于最终装配。

## 交付验收

- [ ] 实测读数更新，拔掉土壤探头后显示暂无数据。
- [ ] 手机切屏后设备确认，断网时显示待同步。
- [ ] 模拟五天到期只播放一次指定 MP3，确认后重启计时。
- [ ] 刘看山解释可追溯到读数，模型失败时有本地提示。
- [ ] 换兴趣后早报候选变化，手机原文链接正确。
- [ ] 断网仍能读土壤、操作触屏、播放提醒、浏览缓存。
- [ ] 单手抽出水仓、装水推回，棉绳无卡滞、外壳无漏水，USB 插头可完全插到底。
